Travel & Accommodation Booking Platform

Project Documentation Report

Frontend: React, TypeScript, Vite, Material UI
Backend: Express API deployed on Render
Author: Sali Qasarwi

1. Project Overview

Travelio is a web application for browsing hotels, searching accommodations, viewing hotel details, adding rooms to a cart, completing bookings, and managing travel reservations. The project also includes an admin dashboard for managing cities, hotels, and rooms.

The application was built to satisfy the required travel and accommodation booking platform features, including authentication, home page discovery sections, search results, hotel details, checkout and confirmation, and admin management.

5. Main User Flows

User Flow

  • User logs in using the user demo account.
  • User searches for hotels by destination, dates, guests, and rooms.
  • User filters and reviews available hotel results.
  • User opens a hotel details page and reviews rooms, gallery, reviews, and location.
  • User adds a room to the cart and continues to checkout.
  • User completes guest information, payment details, and special requests.
  • User receives a booking confirmation.

Admin Flow

  • Admin logs in using the admin demo account.
  • Admin navigates between Cities, Hotels, and Rooms.
  • Admin searches and reviews entity tables.
  • Admin creates new entities using form drawers.
  • Admin updates existing records by selecting table rows.
  • Admin deletes records using row actions.

7. Architecture and Folder Structure

The frontend uses a feature-based folder structure. This keeps each domain area close to its pages, components, API calls, types, tests, and utilities.

Key folders:

  • src/app: application layout, providers, and router.
  • src/features/auth: login, auth API, guards, and auth storage.
  • src/features/home: home page sections and API calls.
  • src/features/search: search results, filters, sorting, and search utilities.
  • src/features/hotel: hotel details, gallery, rooms, reviews, and location.
  • src/features/cart: cart context, storage, and cart page.
  • src/features/checkout: checkout steps and validation.
  • src/features/confirmation: booking confirmation display and print support.
  • src/features/admin: admin pages, grids, forms, and management API.
  • src/shared: reusable API client, components, theme, i18n, and utilities.

8. API Integration

The frontend reads the backend base URL from VITE_API_URL. The shared Axios client sends requests to the deployed Express API.

Current API base URL: https://travel-and-accomodation-booking-backend.onrender.com/api

Main integrated endpoint groups:

  • Authentication: login/authenticate user and admin accounts.
  • Home: featured deals, trending destinations, and recently visited hotels.
  • Search: hotel search and amenities.
  • Hotel: details, gallery, available rooms, and reviews.
  • Booking: create bookings and retrieve booking details.
  • Admin: navigation, cities, hotels, and rooms management.

9. UI and UX Features

The interface supports common user expectations for a booking platform:

  • Clear login page with validation and API error feedback.
  • Persistent top navigation for user pages.
  • Admin layout with side navigation for management tasks.
  • Arabic and English localization.
  • Light and dark theme switching.
  • Responsive layouts for desktop and mobile screens.
  • Reusable cards, forms, data grids, dialogs, and toolbar patterns.

10. Testing and Quality

The project includes unit and component tests across major features. It also uses formatting and linting tools to keep the codebase consistent.

Useful commands:

  • npm run build: production build check.
  • npm run test:run: run the test suite once.
  • npm run lint: run ESLint checks.
  • npm run format:check: verify formatting.
  • npm run storybook: view isolated component stories.

11. Deployment Summary

Frontend on Vercel

  • Framework preset: Vite.
  • Build command: npm run build.
  • Output directory: dist.
  • Environment variable: VITE_API_URL.

Backend on Render

  • Runtime: Node.js.
  • Build command: npm install.
  • Start command: npm start.
  • Swagger documentation available at /api-docs.
